# Jesse Barnabs: Portfolio Website

A personal portfolio website built with HTML, CSS and JavaScript. This version adds interactive features to my earlier HTML and CSS portfolio while keeping the responsive design.

## Files
- `index.html`: the page content (header, navigation, About, Projects, Contact, footer)
- `style.css`: colours, layout (Flexbox and Grid), hover effects, animations and the mobile layout
- `script.js`: all the JavaScript for the interactive features

## JavaScript features
- **Hamburger menu:** on small screens the links are hidden behind a button, which opens and closes the menu. The menu closes when a link is clicked.
- **Dynamic greeting:** the welcome line changes to "Good morning", "Good afternoon" or "Good evening" depending on the time.
- **Show more projects button:** adds extra project cards to the page when clicked.
- **Contact form validation:** checks that the name has at least 2 characters, the email is valid, and the message has at least 10 characters. Errors are shown on the page.
- **Automatic footer year:** the year in the footer is filled in by JavaScript.
